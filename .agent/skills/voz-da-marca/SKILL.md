# Skill: /voz-da-marca

Use este procedimento para revisar os textos das páginas e componentes do **Economize+**:

1. **Tom de Voz:**
   - A marca fala como uma amiga que ajuda a economizar no dia a dia: simples, direta, positiva, acolhedora e educativa.
2. **Proibições Estritas:**
   - Remova superlativos ou promessas absolutas não comprováveis: `"melhores preços"`, `"preço baixo de verdade"`, `"garantia do menor preço"`, `"sempre mais barato"`.
   - Substitua por afirmações honestas e verificáveis: `"compare os preços coletados perto de você"`, `"veja onde cada item foi registrado por menos"`, `"acompanhe a data e hora de cada atualização"`.
   - Remova selos genéricos `"Compatível com a LGPD"`.
